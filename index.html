클로드 연결 (API 키)

키는 이 기기의 브라우저에만 저장되고, 클로드 서버(api.anthropic.com)로만 보내집니다. 다른 사람이 쓰는 기기에서는 쓰고 나서 지워 주세요.

하루 놀이 시간

정해진 시간이 지나면 그 판을 끝으로 "오늘은 여기까지"가 나옵니다.

기록 옮기기와 백업

내려받은 파일을 다른 기기(어머니 노트북 등)에서 불러오면 이어서 놀 수 있어요. API 키는 파일에 들어가지 않습니다.

초기화

게임 초기화: 단계·조각·작품·글자별 숙련도를 처음으로 돌립니다. 학습 기록(보고서 재료)과 칭호는 남습니다. 모든 기록 삭제: 학습 기록까지 지웁니다. 두 경우 모두 API 키는 그대로입니다.
