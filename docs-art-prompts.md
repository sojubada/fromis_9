# 한글 별밤 — 그림 의뢰서 (제미나이용)

아이(7세 남아) 한글 학습 앱 "한글 별밤"에 들어갈 그림입니다. 아이가 글자를 맞출 때마다 작품 그림이 한 조각씩 드러나고, 다 맞추면 완성작이 크게 뜹니다. 그래서 **모든 작품은 같은 화풍, 같은 구도 규칙**으로 그려야 한 세트처럼 보입니다.

## 1. 공통 규격 (모든 그림)

| 항목 | 값 |
|---|---|
| 크기 | 1024×1024 정사각형 (작품·아이콘), 배경만 1920×1080 |
| 파일 | PNG. 작품과 아이콘은 **투명 배경** (안 되면 단색 `#FFF7E3` 크림색 배경) |
| 구도 | 대상 하나만, 화면 중앙, 가장자리에 **12% 여백**. 잘리는 부분 없음 |
| 금지 | 글자·숫자·로고·상표·워터마크 없음. 실제 브랜드 블록(레고 등)의 로고·미니피규어 얼굴 없음 |
| 이름 | 아래 표의 파일명 그대로 저장 |

### 공통 스타일 문장 (모든 프롬프트 맨 앞에 붙임)

```
STYLE: A toy built from colorful plastic interlocking building bricks, chunky stacked blocks with visible round studs on top, clean glossy plastic material, soft studio lighting from the upper left, gentle shadows, saturated primary colors, rendered like a high-quality 3D product photo of a toy. Friendly and cute proportions suitable for a 7-year-old boy. Single subject centered, generous margin on all sides, nothing cropped. Isolated on a transparent background. No text, no letters, no numbers, no logos, no brand marks, no minifigure faces, no watermark. Square 1024x1024.
```

> 제미나이가 투명 배경을 못 만들면 "isolated on a flat solid cream background #FFF7E3, no gradient, no floor, no shadow outside the subject"로 바꿔 주세요.

### 품질을 올리는 요령
- 한 작품마다 **3장씩** 뽑고 가장 또렷하고 정면성이 좋은 것을 고르세요.
- 뽑힌 그림이 마음에 들면 "Keep exactly this style, same lighting, same brick scale" 라고 이어서 다음 작품을 요청하면 세트 통일이 잘 됩니다.
- 블록 스터드가 너무 작아지면 "larger bricks, fewer pieces, each stud clearly visible" 추가.
- 대상이 너무 사실적이면 "more toy-like, rounder, simpler shapes" 추가.

## 7. 업로드 방법

1. 위 파일명으로 저장한 PNG를 이 대화에 한 번에 올려 주세요(한 번에 여러 장 가능).
2. 제가 크기를 맞추고 용량을 줄여(WebP) 앱에 넣습니다.
3. 작품 그림은 **4×3 = 12조각 퍼즐**로 잘라서, 정답 하나에 한 조각씩 드러나게 합니다. 지금의 블록 픽셀 그림은 그림이 없는 작품에만 남깁니다.
4. 우선순위: **작품 16장 → 문 아이콘 4장 → 조각 아이콘 → 배경 → 마스코트** 순서로 보내 주시면 들어오는 대로 반영하겠습니다. 세계 하나(4장)만 먼저 보내셔도 됩니다.
