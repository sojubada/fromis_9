# 한글 별밤 탐험

한글을 막 읽기 시작한 아이를 위한 학습 앱입니다. 공룡·곤충·로봇·블록 네 세계를 탐험하며 글자를 읽으면 조각이 떨어지고, 조각을 모아 그림을 완성합니다. 클로드가 아이의 수준에 맞춰 난이도를 조절합니다.

HTML 한 장으로 돌아갑니다. 방향키·엔터·게임패드로 조작하고, 서버나 설치가 필요 없습니다.

## 실행

- **웹**: GitHub Pages가 켜져 있으면 `https://sojubada.github.io/fromis_9/` 에서 바로 실행됩니다. (저장소 Settings → Pages → Source 를 *GitHub Actions* 로 선택)
- **오프라인**: Releases 의 zip 을 풀고 `index.html` 을 크롬/엣지로 엽니다.

## 기능

- 8단계 적응형 난이도(정답률·반복 간격 기반), 읽기·듣고 고르기·그림 낱말·글자 합치기 문제
- 오늘의 목표(2판), 출석 도장·연속 출석, 칭호, 번개 도전, 작품 완성 보상
- **클로드 연결**: 부모님 화면 → 설정에서 Anthropic API 키를 넣으면 클로드가 다음 문제를 고르고 보고서를 씁니다. 키는 이 기기의 브라우저(localStorage)에만 저장되며 `api.anthropic.com` 으로만 전송됩니다. 키가 없어도 앱이 스스로 문제를 고릅니다.
- **학습 기록 누적**: 푼 문제마다 글자·종류·정답 여부·걸린 시간·시간대·고른 오답을 최근 1,500문제까지 보관합니다.
- **학습 보고서**: 부모님 화면 → 학습 보고서에서 요청할 때 만듭니다. 약한 자모, 헷갈리는 글자 쌍, 시간대·속도·힌트 패턴, 집에서 해 볼 놀이를 정리합니다. `.md` 로 내려받을 수 있고, 클로드가 남긴 분석 메모는 이후 문제 출제에 쓰입니다.
- **게임 초기화**: 단계·조각·작품을 처음으로(학습 기록·칭호는 보존) / **모든 기록 삭제**. 실수 방지를 위해 덧셈 문제(부모 확인)를 풀어야 합니다.
- 하루 놀이 시간 제한, 기록 내려받기·불러오기(기기 간 이동·백업)

## 개인정보

- 가족 사진을 쓰는 깜짝 이벤트(`img/ev01.webp` … `ev11.webp`)는 공개 저장소에 올리지 않도록 `.gitignore` 처리했습니다. 로컬 `img/` 폴더에 같은 이름으로 넣으면 자동으로 나타나고, 없으면 이벤트는 건너뜁니다.
- API 키는 백업 파일에 포함되지 않습니다.
